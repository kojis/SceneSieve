SceneSieve 3.24 — standalone Windows app with first-run downloads

STARTING
Run SceneSieve-Windows-Standalone-v3.24.exe. No Python, mpv, FFmpeg, or Ollama
installation is required. The executable contains only the app and setup code.
First launch downloads checksum-pinned Python/support libraries, mpv, FFmpeg,
7-Zip's extractor, and Ollama. This requires internet access and several GB of
free disk space. Progress appears in the setup window. If a download fails,
restart the same executable: verified completed downloads are reused.
Subsequent launches verify the installed assets and repair missing/changed files.
No administrator privileges are required.

STORAGE
%LOCALAPPDATA%\SceneSieve\
  app-*          Versioned application code
  python-3.12.10  Private Python and support libraries
  assets         Player, encoder, AI service and extractor
  models\vision  Downloaded Ollama models
  models\speech  Downloaded speech models
  downloads      Verified installation/download cache
  data           Settings, waveform cache, scan checkpoints and service logs
  setup.log      First-run setup/repair details
Downloads contact the distributors listed in runtime-manifest.json. Scans and
speech transcription process media locally. No video is uploaded for inference.
Downloaded models are reused; internet is needed for new models/catalog refresh
and subtitle URLs, but not for scanning with a cached model.

VISION MODELS
The model selector lists downloadable local vision variants as well as installed
models. Find models refreshes the official Ollama catalog. Cloud-only and Mac-only
MLX tags are excluded. Choose a family first, then a variant where available. The adjacent description
explains expected speed/resource tradeoffs; these are not gore benchmark scores.
Models marked [download on scan] download automatically when Scan is
pressed, then scanning begins. Capability checks reject non-vision/cloud models.
Large variants can require substantial disk, RAM and GPU memory; availability in
the catalog does not mean that every model fits your computer. Visual categories are empty until you select a preset or enter categories. Detection can miss content or produce false matches.

EDITOR
Drop/open a video. Playback, waveform, timeline, range list and details share the
main screen. Drag the divider below the timeline to allocate space to the editor.
The lower panels scroll on smaller screens. Audio waveform analysis is cached.
Space: play/pause (or mark start/end if the checkbox is enabled).
Left/Right or comma/period: frame step. Ctrl+Left/Right: 5 seconds.
I/O: mark in/out, then Add selected range. M: mark start/end and add the range.
[ / ]: previous/next range. + / - or wheel: zoom. Shift-wheel: pan. Ctrl+0: fit.
Shift-drag timeline: select a new range. Drag a selected edge to trim.
Shift-click/Ctrl-click/drag across list rows: select multiple entries.
Enable selected, Disable selected and Remove selected act on all selected rows.
Double-click one row to edit its times, action and audio level inline.
Red: video cuts. Blue: word attenuation. Purple: audio gain adjustments.
The original-video clock is retained while editing. Selecting a range or jogging
pauses original footage; switch Filtered playback on to hear/see the filters.

AUDIO AND SUBTITLES
Use the Audio / subtitles / export tab.
- Generate subtitles / detect speech: downloads the chosen speech model on first
  use, then transcribes locally on CPU with word timestamps. Base is the default;
  larger models take longer. Generated words are grouped into readable export cues.
- Import subtitles: SRT, VTT, ASS or SSA.
- Use embedded subtitles: select an existing text subtitle track. Bitmap subtitles
  require OCR, which is not included; generate speech subtitles instead.
- Find matching subtitles: searches Internet Archive without an account, or
  OpenSubtitles with your API key. Review title, language, release/file, match and
  rights information before downloading. OpenSubtitles can match the video hash;
  title matches are approximate. Verify timing and use the offset field as needed.
  Public/free access does not guarantee an open reuse licence. View source to
  check the individual upload. API keys remain in memory for the dialog session.
  Searches send the title and, for OpenSubtitles, file hash; video is not uploaded.
- Subtitle URL: paste a direct HTTPS link to a subtitle file.
- Enter comma-separated words/phrases and click Find words. Word lists can be
  saved/loaded as text files. Matches appear as editable ranges with action duck.
- Word audio remaining sets the level during each new match: 0% mutes, 10% retains
  one tenth amplitude. Edit selected changes an existing match's level. Video is
  not cut for duck or gain actions. Enabled word matches are omitted from filtered
  subtitles. Disable a match to retain its original audio and subtitle text.
- Imported/embedded subtitles usually provide sentence timing, not word timing;
  those matches attenuate the entire cue until you trim them. Speech timestamps
  are estimates as well; review boundaries before exporting.
- Detect audio levels finds sustained loud/quiet RMS regions and adds editable
  gain suggestions toward Target RMS (limited to +12/-36 dB by the detector).
  Digital silence is excluded from quiet-region detection.
- Even out loud/quiet audio applies dynamic normalization and peak limiting.
  Normalization and gain run before word attenuation so filtered words stay quiet.
The vertical slider/mute controls preview volume (0–150%); the adjacent meter is
an estimated source-waveform peak, not a hardware output meter. Preview volume
is not baked into exports. Use gain ranges/normalization for exported changes.

OUTPUT
Output folder sets a remembered destination for Save scenes, Export player file,
filtered media and subtitles. Each save dialog still allows another destination.
Save scenes stores video cuts, audio filters and transcript in the scene JSON.
Kodi EDL supports video cuts and complete mutes; partial attenuation, gain and
normalization require a rendered media export.
Export filtered video creates MP4/MKV with excluded scenes removed, selected audio
adjustments applied, and a filtered subtitle track when a transcript is loaded.
Export filtered audio creates M4A/WAV/FLAC with the same timing/cuts/audio filters.
Export filtered subtitles creates an SRT retimed to the filtered video.
A rendered export also writes a matching .filtered.srt sidecar when applicable.
Video is re-encoded as H.264. Exports use the first video and first audio track;
other original tracks/chapters are not retained. Original media is preserved.
The filtered subtitle track comes from the imported/generated transcript, so load
subtitles first if you want them included. Use a distinct export name.
Cancel operation cancels scans/rendering; speech cancellation takes effect between
transcribed segments, and initial speech-model loading/download can take time.

BLEEPS AND SPOKEN SUBSTITUTES (2.1)
In Audio / subtitles / export, choose a Word treatment before Find words:
- Reduce / mute keeps the existing attenuation controls.
- Bleep tone replaces the marked sound with a 100–4000 Hz tone (default 1000 Hz).
- Spoken replacement uses the default installed Windows system voice. Choose
  Darn!, Heck!, Oh, shoot!, Good grief!, Oh, bother!, or type a custom short phrase.
Replacement volume controls the inserted sound separately from playback volume.
Defaults are 15% peak amplitude; a short fade reduces clicks at the boundaries.
To change existing words, select their rows, open the Audio tab, choose a treatment,
and click Apply to selected. Individual ranges can also be edited inline, including
changing action to bleep or replace, frequency, substitute text and volume.
The original audio in the marked interval is muted. The entire soundtrack in that
interval is replaced, including any music/effects there; this is not voice isolation.
Spoken phrases are sped up if needed to fit; short phrases sound more natural in
short intervals. Timing is never extended. This uses a synthetic Windows voice,
not the original speaker's voice. If Windows has no usable voice, use a bleep or
install a Windows speech voice. No extra voice model or cloud service is required.
Replacement WAVs are cached in LocalAppData/SceneSieve/data/replacement-audio.
Both replacements work during filtered playback and video/audio rendering.
Subtitles show the chosen spoken substitute; bleeped words are omitted.
Overlapping replacement intervals use the earlier interval's sound first, avoiding
stacked tones/voices. Review imported sentence-level matches and trim their edges.
Kodi EDL cannot insert sounds: bleep and spoken-replacement ranges export as mutes.

UNIFIED TIMELINE AND SEGMENT VOLUME (2.2)
Waveform and marked ranges share one zoomable timeline. Shift-drag an interval,
then adjust the vertical Segment slider to create an audio gain range. Select
existing audio ranges to change their volume together. The control shows dB:
gain ranges use -60 to +12 dB; word attenuation is capped at 0 dB and -60 mutes it.
For bleeps and spoken substitutions, the slider changes the inserted sound level.
Video cut ranges are not converted into audio ranges by the slider. The separate
Preview slider changes only listening volume. Switch Filtered playback on to
audition segment changes. Save scenes retains all edits in JSON.
Speech detection also offers a main model size followed by applicable variants;
descriptions explain speed and language tradeoffs.

PLAYER EXPORTS (2.2)
Export player file offers:
- Kodi EDL: cuts and complete mutes. Save alongside the original video using its
  base name. Bleeps and spoken replacements become mutes.
- MPlayer EDL: cuts and complete mutes; use mplayer -edl edits.edl video.mkv.
- mpv EDL: retained video sections only; open the generated .mpv.edl in mpv.
- VLC playlist: retained sections as separate XSPF entries. Open in VLC. Playback
  transitions may pause, and seeking accuracy depends on the player/version.
Compatibility warnings appear before saving and after saving. Sidecars/playlists
cannot preserve all volume, normalization, replacement sound or subtitle edits.
Use Export filtered video/audio to bake those edits into a playable media file.
Keep source media at its existing path for mpv and VLC exports, or re-export after
moving it. Scene JSON remains the full editable project representation.

DIALOGUE EXCERPTS AND GAIN AUTOMATION (2.4)

110 characters. Existing sentence-level subtitle cues remain intact. This is display
grouping only: original word timestamps remain available for precise filtering.
The editor uses a compact dark theme with waveform and gain combined in one graph.
Gain ranges have a horizontal line across their interval in the shared waveform
graph. Higher lines mean louder gain; 0 dB is unchanged. Drag a segment line up or
down to adjust it from -60 to +12 dB, then release to save the change to the project.
A dot and dB label identify each line; muted colors indicate disabled ranges.
Create a gain interval by Shift-dragging a range and using the Segment slider.
Use Filtered playback to audition adjustments, and render media to preserve gain
for players whose sidecar formats cannot store it. The gain overlay represents each
individual range; overlapping gains and normalization can affect the final mix.

VISUAL EFFECTS AND AUDIO DISTORTION (3.22)
